## 🚀 GitHub Pages Deployment Instructions

1. Push your code to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Update Raheena Janeesh Portfolio with verified contact details"
   git remote add origin https://github.com/YOUR_USERNAME/raheena-janeesh-portfolio.git
   git branch -M main
   git push -u origin main
   ```
2. In your repository on GitHub:
   - Go to **Settings** -> **Pages**.
   - Set **Source** to `Deploy from a branch` (`main` branch, `/ (root)` folder).
   - Click **Save**.

Your portfolio will automatically publish to `https://YOUR_USERNAME.github.io/raheena-janeesh-portfolio/`.
